# Product overview

## What Nusa.Business is

A **multi-tenant local business directory** for Indonesia. Visitors discover authentic businesses by island and place; field teams register listings on the ground; owners claim and manage them; vendors may open a shop.

Inspired by [bali.business](https://bali.business), expanded nationally under **nusa.business** (*nusa* = island).

## What it is not

- Not a government company-registration portal  
- Not a WordPress / PHP plugin stack  
- Not a Vercel-only Next.js app  

## Value props (launch)

- **No registration fees** for standard listings  
- **No monthly charges** for the free tier  
- **No commission** on sales at launch (0%)  
- English + Bahasa presence for tourists, expats, and locals  

## Surfaces

1. **Public directory (Astro)** — SEO, place hubs, listing profiles, reviews, booking request forms  
2. **Portal** — owner listings, claims, field ops, bookings inbox, vendor shop admin  
3. **API** — shared JSON backend  

## Relationship to bali.business

bali.business remains the live WordPress prototype. Nusa reimplements capabilities and later absorbs Bali inventory via export + 301s ([migration-bali.md](./migration-bali.md)).
