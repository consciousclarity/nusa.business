# Security policy

## Supported versions

The `main` branch is the only supported line during early development.

## Reporting a vulnerability

Email or privately message the maintainers (GitHub: [@consciousclarity](https://github.com/consciousclarity)). Do not open a public issue for active exploits.

Include:

- Affected component (`apps/api`, portal, web, docker)
- Reproduction steps
- Impact assessment

## Known MVP limitations

Documented in [docs/ops/security.md](docs/ops/security.md) — demo auth is not production-ready.
